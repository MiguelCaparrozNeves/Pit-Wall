# 🏎️ PITWALL — GP de São Paulo 2026


Landing page temática desenvolvida para estudos de **HTML5** e **CSS3**, inspirada no **Grande Prêmio de São Paulo de Fórmula 1** no Autódromo de Interlagos. O projeto traz uma interface moderna em *dark mode*, tipografia esportiva e identidade visual inspirada nas pistas de corrida.

---

## ✨ Funcionalidades e Seções

* **Barra de Navegação (`Navbar`):** Menu fixo com links de âncora para navegação rápida entre as seções e botão de destaque para compra de ingressos.
* **Seção Hero:** Apresentação do evento com dados do circuito (71 voltas, 4.309m de extensão e 15 curvas), imagem estilizada com recorte diagonal (`clip-path`) e faixa decorativa estilo zebra de pista.
* **01. Grid de Pilotos:** Cards individuais estilizados com as cores das respectivas escuderias:
  * **#16 Charles Leclerc** — Ferrari
  * **#81 Oscar Piastri** — McLaren
  * **#63 George Russell** — Mercedes
  * **#5 Gabriel Bortoleto** — Audi
* **02. Classificação:** Tabela completa de pontuação do campeonato com destaque visual para o líder e estrutura de filtros por nome do piloto e equipe.
* **03. Ingressos:** Tabela de valores por setor (*Arquibancada A*, *Setor da Reta* e *Box VIP*), alerta de disponibilidade de vagas e formulário completo de reserva com upload de comprovante de meia-entrada.
